# 2026香港展会执行管理系统

内部使用的小型 Web App，用于管理 2026 年 9 月 2-4 日香港亚洲果蔬展（Asia Fruit Logistica）相关的行程、酒店、客户接待和 AI 辅助信息。

## 当前状态

- 项目已创建
- 正在进行第一阶段：页面结构与数据库骨架
- 技术路线：React + SQLite

## 核心场景

- 展会总控台
- 行程管理
- 酒店管理
- 老板信息
- 客户管理 CRM
- 客户接待攻略
- 展会每日计划
- AI 辅助

## 首版原则

- 先做可运行的最小版本
- 先支持录入、查看、编辑
- 暂不做复杂权限、多端同步、消息推送

## 目录说明

- `素材/`：参考资料、图片、原始附件
- `源文件/`：可编辑源文件
- `输出/`：最终交付或导出文件
- `任务清单.md`：开发任务拆解
